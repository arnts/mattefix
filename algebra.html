4.1Polynomdivisjon

Polynomdivisjon er som vanlig deling, men med polynomer. Du deler ett polynom på et annet og får en kvotient — og kanskje en rest.

Dividend = Kvotient · Divisor + Rest

Sammenlign med tallregning:

  • 17 ÷ 5 = 3 rest 2
  • 17 = 3 · 5 + 2 ✓

Det samme gjelder for polynomer. Hvis resten er 0, har vi delt opp polynomet i faktorer.

Ord du må kunne:

  • Dividend: polynomet vi deler på
  • Divisor: det vi deler med
  • Kvotient: svaret
  • Rest: det som er igjen

Algoritmen, steg for steg

La oss dele (x³ − 4x² + x + 6) på (x − 2).

Sett opp som langdivisjon. Skriv begge polynomer i synkende grad. Husk å sette inn 0 for ledd som mangler. (x³ − 4x² + x + 6) ÷ (x − 2)
Del høyeste ledd i dividenden på høyeste ledd i divisor. x³ ÷ x = x² ← første ledd i kvotienten
Gang kvotient-leddet med hele divisor, og trekk fra. x² · (x − 2) = x³ − 2x² (x³ − 4x²) − (x³ − 2x²) = −2x²
Hent ned neste ledd fra dividenden. −2x² + x
Gjenta: del nytt høyeste ledd på divisor. −2x² ÷ x = −2x ← nytt ledd −2x · (x − 2) = −2x² + 4x (−2x² + x) − (−2x² + 4x) = −3x
Hent ned siste ledd og gjenta. −3x + 6; −3x ÷ x = −3 −3 · (x − 2) = −3x + 6 (−3x + 6) − (−3x + 6) = 0 ← rest
Svar: kvotient er x² − 2x − 3, rest 0.

Oppstilling som «trapp»

Her er hele utregningen ovenfor satt opp på den tradisjonelle måten:

Kvotient over streken, rest under x² − 2x − 3 ──────────────────────── (x − 2) | x³ − 4x² + x + 6 | x³ − 2x² ──────────────── | −2x² + x | −2x² + 4x ──────────────── | −3x + 6 | −3x + 6 ──────────────── | 0
x³ − 4x² + x + 6 = (x − 2)(x² − 2x − 3)

Når det ikke går opp

Hvis resten ikke blir 0, skriver vi resultatet slik:

Dividend / Divisor = Kvotient + Rest / Divisor

Eksempel: (x² + 3x + 5) ÷ (x + 1) gir kvotient (x + 2) og rest 3, så:

(x² + 3x + 5) / (x + 1) = (x + 2) + 3/(x + 1)
Sjekk svaret ditt: kvotient · divisor + rest skal alltid bli dividenden tilbake. Bruk dette for å luke ut feil!

Når et ledd «mangler»

Hva om vi skal dele (x³ + 1) på (x + 1)? Polynomet har ingen x²- eller x-ledd. Trikset er å skrive dem inn med koeffisient 0, så kolonnene holder seg på plass:

x³ + 1  =  x³ + 0·x² + 0·x + 1
Del høyeste ledd: x³ ÷ x = x². x² · (x + 1) = x³ + x² (x³ + 0x²) − (x³ + x²) = −x²
Hent ned 0x: −x² + 0x. Del: −x²/x = −x. −x · (x + 1) = −x² − x (−x² + 0x) − (−x² − x) = x
Hent ned 1: x + 1. Del: x/x = 1. 1 · (x + 1) = x + 1 (x + 1) − (x + 1) = 0
Svar: x³ + 1 = (x + 1)(x² − x + 1).
Vanlig feil: å hoppe rett til neste ledd uten å skrive «0·» for de manglende. Da forskyver kolonnene seg og hele utregningen blir feil.

4.2Anvendelse av polynomdivisjon

Polynomdivisjon er ikke bare en regneteknikk — det er et kraftig verktøy for å faktorisere polynomer og finne nullpunkter.

Faktorsetningen

Hvis f(a) = 0, så er (x − a) en faktor i f(x).

Med andre ord: hvis du finner ett nullpunkt, kan du «trekke det ut» som en faktor og dele bort. Polynomet som blir igjen har lavere grad og er enklere å løse.

Strategi for å faktorisere et polynom

Heltallsrot-tipset: hvis polynomet har et heltalls-nullpunkt, må det være en divisor av konstantleddet.

For f(x) = x³ − 4x² + x + 6 er konstantleddet 6, så prøv ±1, ±2, ±3, ±6 — ikke 4, 5, 7 eller andre tall. Det sparer mye tid på prøven.

Gjett et nullpunkt. Test divisorene av konstantleddet, for eksempel ±1, ±2, ±3, ±6.
Sjekk: regn ut f(gjettet tall). Er svaret 0, har du funnet et nullpunkt.
Bruk polynomdivisjon til å dele polynomet på (x − nullpunkt).
Faktoriser videre hvis det går (gjenta, eller bruk abc-formel for andregrads-faktoren).

Eksempel: faktoriser f(x) = x³ − 4x² + x + 6

Test små tall. f(1) = 1 − 4 + 1 + 6 = 4 ≠ 0 f(−1) = −1 − 4 − 1 + 6 = 0 ✓
Vi vet: (x + 1) er en faktor. Del polynomet på (x + 1). x³ − 4x² + x + 6 = (x + 1) · (x² − 5x + 6)
Faktoriser andregradsleddet. Bruk abc-formel eller prøv: hva har sum 5 og produkt 6? Tallene 2 og 3. x² − 5x + 6 = (x − 2)(x − 3)
Sett alt sammen. f(x) = (x + 1)(x − 2)(x − 3)
Nullpunkter: x = −1, x = 2, x = 3.

Forkorting av rasjonale uttrykk

Polynomdivisjon brukes også for å forkorte brøker med polynomer:

(x² − 5x + 6) / (x − 2) = (x − 2)(x − 3) / (x − 2) = x − 3

Når både teller og nevner har samme faktor, kan vi forkorte den bort (bortsett fra på selve nullpunktet).

Tips: Konstantleddet i polynomet (det uten x) er produktet av alle nullpunktene (med fortegnsregler). For x³ − 4x² + x + 6 er det 6 = (−1)·2·3·(−1) = 6 ✓.

4.3Likningssystem

Et likningssystem er to (eller flere) likninger som skal være sanne samtidig. Løsningen er verdiene som tilfredsstiller alle likningene.

{ ax + by = c    (likning 1)
  dx + ey = f    (likning 2) }

Tre måter å løse på

Innsetningsmetoden

Løs det ene uttrykket for én variabel og sett inn i det andre.

Eksempel:

I:   y = 2x + 1
II:  3x + y = 11
Sett inn uttrykket fra I i II. y er allerede løst i I. 3x + (2x + 1) = 11
Løs for x. 5x + 1 = 11 ⇒ 5x = 10 ⇒ x = 2
Sett tilbake i I for å finne y. y = 2·2 + 1 = 5
Svar: (x, y) = (2, 5).

Addisjonsmetoden (eliminasjon)

Gang likningene slik at en variabel forsvinner når du legger sammen.

I:   2x + 3y = 12
II:  4x − 3y = 6
Legg sammen I + II. 3y og −3y kansellerer. (2x + 3y) + (4x − 3y) = 12 + 6 6x = 18 ⇒ x = 3
Sett inn i I. 2·3 + 3y = 12 ⇒ 3y = 6 ⇒ y = 2
Svar: (x, y) = (3, 2).
Hvis variablene ikke kansellerer direkte, gang en (eller begge) likninger med et passende tall først.

Grafisk metode

Tegn begge likninger som linjer. Skjæringspunktet er løsningen.

I:  y = 2x + 1
II: y = −x + 4

Linjene krysser i (1, 3). Det er løsningen.

Praktisk: grafisk er fin for å «se» løsningen, men nøyaktigheten er begrenset av hvor godt du kan lese av grafen. Bruk algebra for eksakte svar.

Hva skjer hvis likningene ikke har én løsning?

Én løsning

Linjene krysser i ett punkt. Vanligst!

Ingen løsning

Parallelle linjer — møtes aldri.

Uendelig mange

Samme linje to ganger. Alle punkter er løsninger.

Hint i regnestykket

Får du 0 = 0 når du regner — uendelig mange løsninger.
Får du 0 = 5 (eller annet feil) — ingen løsning.

Lek med to likninger og se skjæringen

Dra på skyverne under for å endre stigningstall og konstantledd. Skjæringspunktet (om det finnes) regnes ut og markeres i sanntid. Prøv å gjøre linjene parallelle eller sammenfallende!

System med tre ukjente

Tre likninger med tre ukjente løses på samme måte: bruk addisjon til å eliminere én variabel om gangen, så du står igjen med to likninger og to ukjente.

Strategi: 3 likninger → 2 likninger → 1 likning. Løs bakover.

Fullt eksempel: tre ukjente

I:    x + y + z = 6
II:   2x − y + z = 3
III:  x + 2y − z = 2
Eliminer z først. Legg sammen I og III (z + (−z) = 0). I + III: 2x + 3y = 8   (kall denne IV)
Eliminer z igjen. Legg sammen II og III. II + III: 3x + y = 5   (kall denne V)
Nå har vi to likninger med to ukjente. Løs IV og V. Fra V: y = 5 − 3x Sett inn i IV: 2x + 3(5 − 3x) = 8 2x + 15 − 9x = 8 ⇒ −7x = −7 ⇒ x = 1
Finn y: y = 5 − 3·1 = 2.
Finn z: sett x og y inn i I. 1 + 2 + z = 6 ⇒ z = 3
Svar: (x, y, z) = (1, 2, 3).
Sjekk i alle tre likninger. I: 1 + 2 + 3 = 6 ✓ II: 2 − 2 + 3 = 3 ✓ III: 1 + 4 − 3 = 2 ✓

4.4Ulikheter

En ulikhet er som en likning, men med <, >, ≤ eller ≥ i stedet for likhetstegn. Løsningen er som regel et intervall, ikke ett enkelt tall.

Symbolene: < (mindre enn), > (større enn), ≤ (mindre eller lik), ≥ (større eller lik)

Regnereglene

  • Du kan legge til/trekke fra samme tall på begge sider — ingen problem.
  • Du kan gange/dele med et positivt tall — ingen problem.
  • Når du ganger eller deler med et negativt tall, må du snu ulikhetstegnet!
Eks: −2x < 6  ⇒  del på −2 og snu  ⇒  x > −3

Lineære ulikheter

Eksempel: 3x − 4 ≥ 8
Legg til 4 på begge sider. 3x ≥ 12
Del på 3 (positivt — ingen snu). x ≥ 4
Svar: x ≥ 4. På intervallnotasjon: [4, →⟩.

Andregradsulikheter

For å løse x² − x − 6 < 0:

Faktoriser/finn nullpunktene til andregradsuttrykket. x² − x − 6 = (x − 3)(x + 2) Nullpunkter: x = −2 og x = 3
Lag en fortegnslinje for hvert ledd, og kombiner.
Les av: uttrykket er negativt mellom nullpunktene. −2 < x < 3

Fortegnsskjema

Et fortegnsskjema er et verktøy for å se hvor et uttrykk er positivt eller negativt. Slik bruker du det:

Faktoriser uttrykket. Hver faktor får sin egen rad.
Marker nullpunktene til hver faktor på tallinjen.
Test ett tall i hvert intervall. Velg et enkelt tall (f.eks. 0, eller noe utenfor) og regn ut fortegnet til faktoren der.
Multipliser fortegnene kolonnevis for å finne fortegnet til hele uttrykket.

For x² − x − 6 = (x + 2)(x − 3), test x = −5, x = 0, x = 5:

  • x = −5: (−3)·(−8) = +24 (positivt)
  • x = 0: (2)·(−3) = −6 (negativt)
  • x = 5: (7)·(2) = +14 (positivt)

Vi vil ha < 0, så svaret er der produktet er −: −2 < x < 3.

Åpne vs lukkede sirkler: Med < eller > er endepunktet ikke med (åpen sirkel). Med ≤ eller ≥ er det med (lukket sirkel).

4.5Numerisk løsning av likninger

Noen likninger kan vi ikke løse algebraisk — eller det er veldig vanskelig. Da bruker vi en numerisk metode: vi finner et tilnærmet svar med datamaskin eller kalkulator.

Eksempler: x⁵ − x − 1 = 0, ex = 5x, sin(x) = x/2

Idé: en likning er det samme som «hvor er nullpunktet»

For å løse f(x) = g(x) kan vi flytte alt til én side og finne hvor h(x) = f(x) − g(x) = 0.

Med andre ord: vi tegner grafen og leser av der den krysser x-aksen.

Punktene der grafen krysser x-aksen er løsningene.

I GeoGebra:

  • Definer funksjonen f(x) = …
  • Skriv NLøs(f(x) = 0, x) eller Nullpunkt(f)
  • GeoGebra finner alle (eller ett, avhengig av kommandoen).

Sentrale GeoGebra-kommandoer

KommandoHva den gjør
Løs(likning, x)Eksakt løsning (når den finnes algebraisk)
NLøs(likning, x)Numerisk (tilnærmet) løsning
NLøs(likning, x = startverdi)Numerisk søk nær en startverdi
Nullpunkt(f)Alle nullpunkter til en funksjon
Nullpunkt(f, a, b)Nullpunkter mellom a og b

Eksempel: løs ex = 5x

Flytt alt til én side. e^x − 5x = 0
Definer funksjonen i GeoGebra. f(x) := exp(x) − 5x
Tegn grafen og se hvor den krysser x-aksen. Det ser ut til å være to nullpunkter.
Bruk NLøs med startverdier. NLøs(f(x) = 0, x = 0) → x ≈ 0.259 NLøs(f(x) = 0, x = 3) → x ≈ 2.542
Svar: Likningen har to løsninger, ca. x ≈ 0.26 og x ≈ 2.54.
Hvorfor startverdi? Numeriske metoder finner ofte bare ett nullpunkt om gangen — det nærmeste startverdien. Hvis du vet at det er flere, kjør NLøs flere ganger med ulike startverdier.

Mønster og oversikt – velg riktig metode

Her er en rask oversikt for å velge riktig algebra-verktøy:

Du skal …Bruk
Faktorisere et polynom av grad ≥ 3Gjett nullpunkt, så polynomdivisjon
Forkorte (x² − …) / (x − a)Polynomdivisjon
Løse 2 likninger med 2 ukjenteInnsetning eller addisjon
Løse 3 likninger med 3 ukjenteEliminasjon (eller GeoGebra Løs)
Løse en lineær ulikhetSom likning, men husk fortegn ved gange/dele med negativt
Løse en andregradsulikhetFaktoriser, fortegnsskjema, les av
Løse en likning som er «umulig»NLøs i GeoGebra (numerisk)

Tre raske huskeregler

  • Faktorsetningen: f(a) = 0 ⇔ (x − a) er faktor i f.
  • Gange med negativt = snu ulikhetstegnet. Glem aldri.
  • NLøs trenger ofte en startverdi. Tegn grafen først for å se hvor du skal lete.

GeoGebra-guide for algebra

Verktøykassen for kapittel 4. CAS-feltet (linje merket med ÷ eller fx) er det viktigste her.

Polynomdivisjon

GeoGebra kan gjøre polynomdivisjonen for deg!

// Dividere polynomer
Divisjon(x^3 - 4x^2 + x + 6, x - 2)
→ {x² − 2x − 3, 0} (kvotient og rest)

// Faktorisere et polynom direkte
Faktoriser(x^3 - 4x^2 + x + 6)
→ (x − 2)(x − 3)(x + 1)

Likningssystem

// To likninger med to ukjente
Løs({2x + 3y = 12, 4x - 3y = 6}, {x, y})
→ {{x = 3, y = 2}}

// Tre likninger med tre ukjente
Løs({x + y + z = 6, 2x - y + z = 3, x + 2y - z = 2}, {x, y, z})
→ {{x = 1, y = 2, z = 3}}
Husk: krøllparenteser { … } rundt likningssettet og rundt variabel-listen.

Ulikheter

// Lineær ulikhet
Løs(3x - 4 ≥ 8, x)
→ x ≥ 4

// Andregradsulikhet
Løs(x^2 - x - 6 < 0, x)
→ −2 < x < 3
Skriv ≥ som >=, og ≤ som <= hvis spesialtegnet er vanskelig å finne.

Numerisk løsning

// Hvis Løs ikke greier det
f(x) := exp(x) - 5x
NLøs(f(x) = 0, x = 0)
→ x ≈ 0.2592

NLøs(f(x) = 0, x = 3)
→ x ≈ 2.5426

// Alle nullpunkter i et intervall
Nullpunkt(f, -2, 5)

Vanlige feil

1
Glemte krøllparenteser i likningssett. Løs(2x+3y=12, 4x-3y=6, {x,y}) fungerer ikke. Skriv Løs({2x+3y=12, 4x-3y=6}, {x,y}).
2
Brukte = i stedet for :=. f(x) := … definerer en funksjon du kan regne videre med. = er bare en likning.
3
Glemte å snu ulikhetstegnet. Når du regner for hånd og ganger eller deler med negativt — snu! GeoGebra gjør det selv.
4
NLøs uten startverdi gir bare ett svar. Tegn grafen først, og kjør NLøs én gang per nullpunkt med ulike startverdier.
5
Polynomdivisjon: glemte ledd. Hvis polynomet mangler et ledd (f.eks. ingen x²), skriv 0·x² eller bare hold plassen — ellers blir oppstillingen feil.
