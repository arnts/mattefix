1. Algebra

▾

Kvadratsetningene

Del 1
$$(a+b)^2 = a^2 + 2ab + b^2$$
$$(a-b)^2 = a^2 - 2ab + b^2$$
Eks: $(x+3)^2 = x^2 + 6x + 9$
Husk dobbeltproduktet $2ab$!

Konjugatsetningen

Del 1
$$(a+b)(a-b) = a^2 - b^2$$
Eks: $(x+5)(x-5) = x^2 - 25$

Faktorisering

Del 1
  • Felles faktor: $ab + ac = a(b+c)$
  • Konjugat: $a^2 - b^2 = (a+b)(a-b)$
  • Kvadrat: $a^2 \pm 2ab + b^2 = (a \pm b)^2$
  • $x^2 + (p+q)x + pq = (x+p)(x+q)$
Eks: $x^2 - 5x + 6 = (x-2)(x-3)$

Brøkregning

Del 1
$$\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$$
$$\frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c} = \frac{ad}{bc}$$
$$\frac{a}{c} + \frac{b}{c} = \frac{a+b}{c}$$
$$\frac{a}{b} + \frac{c}{d} = \frac{ad+bc}{bd}$$

Forkorting: stryk felles faktor i teller og nevner.

$$\frac{k \cdot a}{k \cdot b} = \frac{a}{b}$$
Eks: $\dfrac{x^2 - 9}{x + 3} = \dfrac{(x+3)(x-3)}{x+3} = x - 3$
IKKE: $\dfrac{a+b}{a} = 1 + b$. Du kan bare forkorte felles faktor, ikke ledd som er adderte.

Potensregler

Del 1
  • $a^m \cdot a^n = a^{m+n}$
  • $\dfrac{a^m}{a^n} = a^{m-n}$
  • $(a^m)^n = a^{mn}$
  • $(ab)^n = a^n b^n$
  • $a^0 = 1 \quad (a \neq 0)$
  • $a^{-n} = \dfrac{1}{a^n}$

Røtter

  • $a^{1/2} = \sqrt{a}$
  • $a^{1/n} = \sqrt[n]{a}$
  • $a^{m/n} = \sqrt[n]{a^m}$
  • $\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}$
  • $\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$
  • $\sqrt{a} \cdot \sqrt{a} = a$
Rasjonaliser: $\dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$
IKKE: $\sqrt{a} + \sqrt{b} \neq \sqrt{a + b}$.
Sjekk: $\sqrt{9} + \sqrt{16} = 3 + 4 = 7$, men $\sqrt{25} = 5$.

Polynomdivisjon

Del polynom på $(x-a)$ slik som vanlig deling.

Dividend = Kvotient · Divisor + Rest

Faktorsetningen:

$$f(a) = 0 \;\Leftrightarrow\; (x - a) \text{ er en faktor i } f(x)$$
Strategi: test $\pm 1, \pm 2, \pm 3 \ldots$ (delere av konstantleddet) til du finner $a$ med $f(a) = 0$.

Standardform

Skriv tall som $a \cdot 10^n$ der $1 \leq a < 10$.

  • $4\,500\,000 = 4{,}5 \cdot 10^6$
  • $0{,}000\,32 = 3{,}2 \cdot 10^{-4}$
Komma flytter til venstre → $n$ positiv. Komma til høyre → $n$ negativ.

2. Likninger og ulikheter

▾

Lineær likning

Del 1
$$ax + b = 0 \;\Rightarrow\; x = -\frac{b}{a}$$

Samle x-ledd på én side, tall på den andre.

Eks: $3x - 5 = 7 \Rightarrow x = 4$

Andregradslikning

Del 1
$$ax^2 + bx + c = 0$$

Spesialtilfeller:

  • $b=0$: $x^2 = -c/a \Rightarrow x = \pm\sqrt{-c/a}$
  • $c=0$: $x(ax+b)=0 \Rightarrow x=0$ eller $x=-b/a$

ABC-formelen

Del 1
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
Eks: $x^2 - 5x + 6 = 0 \Rightarrow x = 2$ eller $x = 3$
Pass på når $b$ er negativ:
$b = -5 \Rightarrow -b = +5$   og   $b^2 = (-5)^2 = +25$ (ikke $-25$).

Diskriminant

Del 1
$$D = b^2 - 4ac$$
  • $D > 0$: to ulike løsninger (graf krysser x-aksen)
  • $D = 0$: én dobbeltløsning (tangerer x-aksen)
  • $D < 0$: ingen reelle løsninger (slipper over)

Sum og produkt

Når $a = 1$, dvs. $x^2 + bx + c = 0$:

$$x_1 + x_2 = -b, \qquad x_1 \cdot x_2 = c$$
Eks: $x^2 - 7x + 12 = 0$. Sum 7, produkt 12 → $x = 3$ eller $x = 4$.

Fortegnsanalyse

  1. Faktoriser uttrykket.
  2. Marker nullpunkter på tallinje.
  3. Test ett tall i hvert intervall.
  4. Multipliser fortegn for produktet.
Eks: $(x-2)(x+3) < 0 \Rightarrow -3 < x < 2$

Likningssystemer

Tre metoder:

  • Innsetning: løs for én variabel og sett inn
  • Addisjon: legg sammen så én variabel forsvinner
  • Grafisk: tegn linjene, finn skjæring
$0=0$ underveis → uendelig mange. $0=5$ → ingen løsning.

Ulikheter

Del 1

Som likninger, men:

Snu tegnet ved gange/dele med negativt tall!
Eks: $-2x < 6 \Rightarrow x > -3$

3. Funksjoner

▾

Lineær funksjon

Del 1
$$f(x) = ax + b$$
  • $a$ = stigningstall = $\dfrac{y_2 - y_1}{x_2 - x_1}$
  • $b$ = y-skjæring ($f(0) = b$)
  • Ettpunktformel: $y - y_1 = a(x - x_1)$

Andregradsfunksjon

Del 1
$$f(x) = ax^2 + bx + c$$
  • Topp/bunnpunkt ved $x = -\dfrac{b}{2a}$
  • $a > 0$: bunnpunkt (parabel åpner opp)
  • $a < 0$: toppunkt (åpner ned)
  • Symmetrisk om $x = -\dfrac{b}{2a}$

Toppunktsform

Andregrad kan også skrives slik:

$$f(x) = a(x - x_0)^2 + y_0$$

$(x_0, y_0)$ leses direkte som topp/bunnpunkt.

Eks: $f(x) = 2(x-3)^2 - 4$ har bunnpunkt $(3, -4)$.

Polynomfunksjon

$$f(x) = a_n x^n + \ldots + a_1 x + a_0$$
  • Grad $n$ → opptil $n$ nullpunkter
  • Faktorisert: $a(x-r_1)(x-r_2)\cdots$
  • Heltallsnullpunkter er delere av konstantleddet $a_0$
Eks: $f(x) = x^3 - 4x^2 + x + 6$. Konstantledd $6$ → test $\pm 1, \pm 2, \pm 3, \pm 6$.

Rasjonal funksjon

$$f(x) = \frac{P(x)}{Q(x)}$$
  • Df: alle $x$ der $Q(x) \neq 0$
  • Loddrett asymptote: der $Q(x) = 0$
  • Vannrett asymptote: verdien grafen nærmer seg når $x \to \pm\infty$
Eks: $f(x) = \dfrac{1}{x-2}$ har asymptoter $x=2$ og $y=0$.

Eksponentialfunksjon

Del 1
$$f(x) = a \cdot b^x \quad (b > 0,\, b \neq 1)$$
  • $a$ = startverdi, $f(0) = a$
  • $b$ = vekstfaktor
  • $b > 1$: vekst   $0 < b < 1$: nedgang
  • Prosentvis endring per periode: $(b - 1) \cdot 100\%$
Eks: $b = 1{,}05 \Rightarrow 5\%$ økning per periode.

Nullpunkter

Del 1

Sett $f(x) = 0$ og løs:

  • Lineær: $x = -b/a$
  • Andregrad: ABC-formel
  • Faktorisert form: hver faktor $= 0$

Nullpunktsetningen

Hvis $f$ er kontinuerlig på $[a, b]$ og

$$f(a) \cdot f(b) < 0$$

(altså motsatt fortegn), finnes det minst ett nullpunkt mellom $a$ og $b$.

Eks: $f(x) = x^3 - 2x - 5$. $f(1) = -6$, $f(3) = 16$. Motsatt fortegn → nullpunkt mellom $1$ og $3$.
Brukes når likningen ikke kan løses algebraisk — kobling til halveringsmetoden (se Python).

Topp- og bunnpunkt

For andregradsfunksjon:

$$x_t = -\frac{b}{2a}, \quad y_t = f(x_t)$$

Eller deriver og sett $f'(x) = 0$.

Stigningstall

Del 1
  • Lineær: $a$
  • To punkter: $\dfrac{\Delta y}{\Delta x}$
  • Tangent i $x = x_0$: $f'(x_0)$

Definisjonsmengde

Hvilke $x$ er tillatt?

  • Brøk: $x$ der nevner $\neq 0$
  • Kvadratrot: $\sqrt{f(x)}$ krever $f(x) \geq 0$
  • Polynom og eksponentialfunksjon: alle reelle tall
  • Praktisk: tid $\geq 0$, lengde $> 0$

Asymptoter

  • Loddrett: $x = a$ der $Q(a) = 0$ og $P(a) \neq 0$
  • Vannrett: $y = $ grenseverdien når $x \to \pm\infty$
  • Sjekk grader: lavere teller → $y = 0$; lik grad → forhold mellom ledende koeffisienter
Hvis både $P(a) = 0$ og $Q(a) = 0$ → hull i grafen, ikke asymptote.

4. Derivasjon

▾

Gjennomsnittlig vekstfart

Del 1

Stigningstall til sekanten mellom to punkter:

$$\frac{f(b) - f(a)}{b - a}$$
Eks: $f(x) = x^2$ fra $x=1$ til $x=4$: $(16-1)/3 = 5$.

Momentan vekstfart

Del 1

Stigningstall til tangenten i ett punkt — det er den deriverte:

$$f'(a) = \text{stigning til tangent i } x = a$$
  • $f'(a) > 0$: $f$ vokser ved $x = a$
  • $f'(a) < 0$: $f$ avtar ved $x = a$
  • $f'(a) = 0$: topp-, bunn- eller terrassepunkt

Derivasjonsregler

Del 1
  • $(c)' = 0$   (konstant)
  • $(x)' = 1$
  • $(x^n)' = n \cdot x^{n-1}$   (potens)
  • $(c \cdot f)' = c \cdot f'$
  • $(f + g)' = f' + g'$
  • $(f - g)' = f' - g'$
Eks: $(2x^4 - 7x^2 + x - 1)' = 8x^3 - 14x + 1$

Topp- og bunnpunkt

Del 1
  1. Deriver: finn $f'(x)$.
  2. Sett $f'(x) = 0$, finn kandidatene.
  3. Lag fortegnsskjema for $f'$.
    • $+ \to -$: toppunkt
    • $- \to +$: bunnpunkt
  4. Sett $x$ i $f$ for $y$-koord.

Tangentlikning

Tangenten til $f$ i punktet $x = a$:

$$y - f(a) = f'(a) \cdot (x - a)$$
Eks: $f(x) = x^2 - 4x + 5$ ved $x=3$. $f(3)=2$, $f'(3)=2$. Tangent: $y = 2x - 4$.

Optimering

«Hva er det største/minste …?»

  1. Skriv et uttrykk av én variabel ved hjelp av begrensningen.
  2. Skriv ned definisjonsmengden.
  3. Deriver, sett $f'(x) = 0$.
  4. Sjekk topp/bunn med fortegnsskjema.
  5. Sjekk også endepunktene på definisjonsmengden.
Klassiker: $100$ m gjerde → største areal er kvadrat $25 \times 25 = 625$ m².

5. Trigonometri

▾

sin, cos, tan

Del 1

I rettvinklet trekant med vinkel $u$:

$$\sin u = \frac{\text{motst}}{\text{hyp}}, \quad \cos u = \frac{\text{hosl}}{\text{hyp}}$$
$$\tan u = \frac{\text{motst}}{\text{hosl}} = \frac{\sin u}{\cos u}$$
SOH-CAH-TOA — si det ut høyt!

Eksakte verdier

Del 1
$u$$0°$$30°$$45°$$60°$$90°$
$\sin u$$0$$\tfrac{1}{2}$$\tfrac{\sqrt{2}}{2}$$\tfrac{\sqrt{3}}{2}$$1$
$\cos u$$1$$\tfrac{\sqrt{3}}{2}$$\tfrac{\sqrt{2}}{2}$$\tfrac{1}{2}$$0$
$\tan u$$0$$\tfrac{\sqrt{3}}{3}$$1$$\sqrt{3}$udef.
Husk: tan(90°) er ikke definert (cos = 0).

Enhetssirkelen

Sirkel med radius 1 og sentrum i origo.

  • Punkt på sirkel: $(\cos u, \sin u)$
  • $\sin^2 u + \cos^2 u = 1$ (Pytagoras)

Supplementvinkler

Del 1

To vinkler som summerer til $180°$ kalles supplementvinkler:

$$u + v = 180° \;\Leftrightarrow\; v = 180° - u$$

Sammenhenger:

$$\sin(180° - u) = \sin u$$
$$\cos(180° - u) = -\cos u$$
Eks: $\sin(150°) = \sin(30°) = \tfrac{1}{2}$, men $\cos(150°) = -\cos(30°) = -\tfrac{\sqrt{3}}{2}$.
Sinus har samme verdi for supplementvinkler — derfor kan sinussetningen gi to løsninger ved SSV.

Tegnregel — kvadranter

Husk ASTC mot klokka:

  • Alle (1. kvadrant, 0–90°): alle positive
  • Sin (2., 90–180°): bare sin positiv
  • Tan (3., 180–270°): bare tan positiv
  • Cos (4., 270–360°): bare cos positiv
Eks: $\cos(120°) = -\tfrac{1}{2}$ (2. kvadrant → cos negativ).

Radianer

  • $360° = 2\pi$ rad
  • $180° = \pi$, $\;90° = \pi/2$
  • $60° = \pi/3$, $\;45° = \pi/4$, $\;30° = \pi/6$
På 1T jobber vi i grader. Sjekk kalkulator i DEG.

Pytagoras

Del 1

I rettvinklet trekant:

$$a^2 + b^2 = c^2$$

$c$ = hypotenus (mot rett vinkel), $a, b$ = kateter.

Eks: $3^2 + 4^2 = 5^2$, så $(3,4,5)$ er rettvinklet.

Sinussetningen

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

Når brukes hva?

  • Finne side: sider oppe (som over)
  • Finne vinkel: snu — $\dfrac{\sin A}{a} = \dfrac{\sin B}{b}$

Brukes ved VSV eller SSV.

Cosinussetningen

$$c^2 = a^2 + b^2 - 2ab\cos C$$

For å finne en vinkel når du har tre sider:

$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

Brukes ved SSS eller SVS.

Arealsetningen

$$A = \tfrac{1}{2} \cdot a \cdot b \cdot \sin C$$

$C$ er vinkelen mellom sidene $a$ og $b$.

Eks: $a=8, b=6, C=60°$. $A = \tfrac{1}{2} \cdot 48 \cdot \tfrac{\sqrt 3}{2} = 12\sqrt{3}$.

6. Geometri

▾

Areal — flate figurer

Del 1
  • Rektangel: $A = l \cdot b$
  • Kvadrat: $A = s^2$
  • Trekant: $A = \tfrac{1}{2} g h$
  • Parallellogram: $A = g \cdot h$
  • Trapes: $A = \tfrac{(a+b)h}{2}$
  • Sirkel: $A = \pi r^2$

Omkrets

Del 1
  • Rektangel: $O = 2(l + b)$
  • Kvadrat: $O = 4s$
  • Trekant: $O = a + b + c$
  • Sirkel: $O = 2\pi r$

Trekant

  • Vinkelsum = $180°$
  • Areal: $A = \tfrac{1}{2} g h$
  • Areal (SVS): $A = \tfrac{1}{2} ab \sin C$
  • Rettvinklet: Pytagoras, sin/cos/tan

Sirkel

  • Areal: $A = \pi r^2$
  • Omkrets: $O = 2\pi r$
  • Diameter: $d = 2r$

Formlikhet

To trekanter er formlike hvis de har samme vinkler.

  • Sider er proporsjonale: $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$
  • Areal-forhold: $k^2$
  • Volum-forhold: $k^3$

Volum

  • Boks: $V = l \cdot b \cdot h$
  • Kube: $V = s^3$
  • Sylinder: $V = \pi r^2 h$
  • Kjegle: $V = \tfrac{1}{3}\pi r^2 h$
  • Pyramide: $V = \tfrac{1}{3}Gh$
  • Kule: $V = \tfrac{4}{3}\pi r^3$

7. Prosent, vekstfaktor og fart

▾

Prosent — det grunnleggende

Del 1
  • $p\%$ av $K$: $\;\dfrac{p}{100} \cdot K$
  • Andel: $\dfrac{\text{del}}{\text{hele}} \cdot 100\%$
Eks: $25\%$ av $200 = 50$.   $15$ av $60 = 25\%$.

Vekstfaktor

Del 1

Tallet du ganger med for å gå fra gammel til ny verdi.

  • Økning $p\%$: $\;v = 1 + \dfrac{p}{100}$
  • Reduksjon $p\%$: $\;v = 1 - \dfrac{p}{100}$
Eks: $20\%$ økning → $v = 1{,}20$.   $30\%$ ned → $v = 0{,}70$.

Sammensatt vekst

Flere endringer etter hverandre — gang vekstfaktorene:

$$v_{\text{tot}} = v_1 \cdot v_2 \cdot v_3 \cdots$$

Samme $p\%$ over $n$ perioder:

$$\text{Ny verdi} = \text{startverdi} \cdot v^n$$
Eks: $10\,000$ kr i $3$ år, $5\%$ rente: $10\,000 \cdot 1{,}05^3 \approx 11\,576$.

Prosentpoeng vs. prosent

Renta gikk fra $3\%$ til $5\%$:

  • Økning: 2 prosentpoeng
  • Prosentvis økning: $\dfrac{2}{3} \cdot 100\% \approx 66{,}7\%$

Ikke bland sammen!

Strekning, fart, tid

Del 1
$$s = v \cdot t, \quad v = \dfrac{s}{t}, \quad t = \dfrac{s}{v}$$
Eks: $80$ km/t i $2{,}5$ t: $s = 200$ km.

km/t ↔ m/s

  • km/t → m/s: del på 3,6
  • m/s → km/t: gang med 3,6
$90$ km/t $= 25$ m/s   ·   $12$ m/s $= 43{,}2$ km/t
Når oppgaven blander enheter — gjør om til samme system først.

8. Eksamensfeller — pass på!

▾

Fortegnsfeil

Riktig: $-(2x - 3) = -2x + 3$

Feil: $-(2x - 3) = -2x - 3$

Hvert ledd inne i parentesen bytter fortegn.

Parentesfeil

Riktig: $(a+b)^2 = a^2 + 2ab + b^2$

Feil: $(a+b)^2 = a^2 + b^2$

Glem aldri dobbeltproduktet $2ab$.

Forkorting over +/−

Du kan IKKE skrive: $\dfrac{a+b}{a} = 1 + b$

Det skal være $\dfrac{a+b}{a} = 1 + \dfrac{b}{a}$.

Forkort bare når både teller og nevner har samme faktor som ganges.

Glemt definisjonsmengde

Kontroller alltid:

  • Brøk: nevner $\neq 0$
  • $\sqrt{x}$: $x \geq 0$
  • Praktisk: tid $\geq 0$, lengde $> 0$

Null i nevner

Hvis du ganger bort en nevner $(x - a)$ må du sjekke om $x = a$ er gyldig svar.

Bryter løsningen kravet → falsk løsning, forkast.

Nullpunkt vs. asymptote

Nullpunkt: $f(x) = 0$ — der grafen krysser x-aksen.

Asymptote: linje grafen nærmer seg uten å nå.

Disse er ikke det samme. En rasjonal funksjon har ofte begge.

Glemt grader (°)

I GeoGebra: $\sin(60)$ regner i radianer ≈ $-0{,}305$.

Du vil ha $\sin(60°) ≈ 0{,}866$. Skriv alltid $°$.

Ulikhet og negativt tall

Når du ganger eller deler med et negativt tall:

Snu ulikhetstegnet! $-2x < 6 \Rightarrow x > -3$

Avrunding for tidlig

La kalkulatoren beholde alle desimaler underveis. Rund av kun til slutt.

Eks: bruk $\sin^{-1}(7\sin 80° / 10)$ direkte, ikke avrundet 0,69.

Glemt $\pm$ ved kvadratrot

Når du tar kvadratrot på begge sider av en likning, må du ha med begge fortegn:

$$x^2 = 9 \;\Rightarrow\; x = \pm 3$$

Bare $x = 3$ er et halvt svar.

Husk også: $\sqrt{x^2} = |x|$, ikke alltid $x$.

Glemt endepunkter ved optimering

Maks/min kan ligge der $f'(x) = 0$ — men også på endene av definisjonsmengden!

Sjekkliste: 1) finn kandidatene $f'(x)=0$, 2) regn ut $f$ i kandidatene og i endepunktene, 3) velg største/minste verdi.

Mini-quiz — 15 raske

▾

Dekk over fasit, prøv selv, klikk «Vis fasit» for å sjekke.

  1. $(x+5)^2 = ?$

    $x^2 + 10x + 25$ — første kvadratsetning.

  2. Faktoriser $x^2 - 16$.

    $(x+4)(x-4)$ — konjugatsetningen baklengs.

  3. Diskriminanten til $x^2 - 5x + 6 = 0$.

    $D = 25 - 24 = 1 > 0$, så to løsninger.

  4. Løs $x^2 - 5x + 6 = 0$.

    $x = 2$ eller $x = 3$ (sum 5, produkt 6).

  5. $\sin(30°) = ?$

    $\dfrac{1}{2}$

  6. $\cos(60°) = ?$

    $\dfrac{1}{2}$ — merk: $\cos(60°) = \sin(30°)$.

  7. $\tan(45°) = ?$

    $1$ (siden $\sin 45° = \cos 45°$).

  8. Areal av trekant med $g = 8$, $h = 6$.

    $A = \tfrac{1}{2} \cdot 8 \cdot 6 = 24$

  9. $f(x) = \dfrac{2}{x-3}$. Definisjonsmengde?

    Alle reelle tall unntatt $x = 3$ (nevner = 0 der).

  10. Linje gjennom $(1, 2)$ og $(3, 8)$ — finn likningen.

    $a = (8-2)/(3-1) = 3$, $y - 2 = 3(x - 1) \Rightarrow y = 3x - 1$.

  11. Deriver $f(x) = 3x^2 - 6x + 4$.

    $f'(x) = 6x - 6$ (potensregel pluss konstant blir 0).

  12. Hvor er bunnpunktet til $f(x) = x^2 - 4x + 1$?

    $f'(x) = 2x - 4 = 0 \Rightarrow x = 2$. $f(2) = -3$. Bunnpunkt $(2, -3)$.

  13. En vare øker med $20\%$ og deretter reduseres med $20\%$. Hva er samlet endring?

    $1{,}20 \cdot 0{,}80 = 0{,}96$. Varen er $4\%$ billigere enn opprinnelig — ikke uendret!

  14. $72$ km/t i m/s?

    $72 / 3{,}6 = 20$ m/s.

Siste liten — sjekkliste på eksamensdagen

▾

Før du begynner

  • Kalkulator i DEG (grader), ikke RAD
  • Skrive- og tegneutstyr klart
  • Pust dypt 3 ganger
  • Les hele oppgavesettet først, kryss av enkle

Strategi i Del 1

  • Hopp over om du står fast — kom tilbake
  • Tegn alltid en figur i geometri
  • Kontroller med innsetting der mulig
  • Skriv eksakte verdier ($\sqrt{2}$, $\pi$), ikke desimaler

Strategi i Del 2

  • Skriv hvilken kommando du brukte
  • Skriv tolkning i kontekst med enhet
  • Oppgi gyldighetsområde
  • Skjermbilder fra GeoGebra

Klassiske «poeng-tyver»

  • Manglende enhet (cm, kr, sek)
  • Glemt $\pm$ ved kvadratrot
  • Avrundet for tidlig
  • Glemt at $-(a-b) = -a+b$
  • Sett inn negativt $b$ uten parentes i ABC

Hvis du står fast

  • Tegn det opp
  • Sett inn et tall og test
  • Skriv ned alt du vet, og hva du skal finne
  • Hopp videre — kom tilbake

Til slutt

Python — programmering i 1T

▾

Eksempler på typiske oppgaver. Klassiske Del 2-mønstre.

Variabler og utskrift

Lagre en verdi og skrive den ut.

pris = 20
antall = 5
total = pris * antall
print(total)   # → 100

For-løkke (kjent antall)

Summer tallene 1 til 10.

sum = 0
for i in range(1, 11):
    sum = sum + i
print(sum)    # → 55
range(1,11) gir 1, 2, …, 10 (stopper FØR 11).

While-løkke (til betingelse)

Hvor mange år før beløpet passerer 2000 kr (5 % rente)?

belop = 1000
ar = 0
while belop < 2000:
    belop = belop * 1.05
    ar = ar + 1
print(ar)    # → 15
Glemmer du å endre variabelen → uendelig løkke!

If-test

Sjekk om en verdi er over en grense.

hoyde = 87
if hoyde > 100:
    print("Over 1 m")
else:
    print("Under 1 m")

Egen funksjon (def)

Definer en matematisk funksjon.

def hoyde(t):
    return -5*t**2 + 20*t

print(hoyde(2))   # → 20
print(hoyde(4))   # → 0

Finn bunnpunkt med små skritt

Del 2

Klassisk eksamensoppgave: bruk en løkke til å finne bunnpunktet til $f(x) = x^2 - 4x + 1$ uten å derivere.

def f(x):
    return x**2 - 4*x + 1

x = -10            # startverdi til venstre for bunnpunktet
delta = 0.001      # liten økning

# Gå til høyre så lenge f fortsatt synker
while f(x + delta) < f(x):
    x = x + delta

print(f"Bunnpunkt: x = {x:.3f}, y = {f(x):.3f}")
# → Bunnpunkt: x = 2.000, y = -3.000
Idé: Når $f(x+\delta)$ ikke lenger er mindre enn $f(x)$, har vi passert bunnpunktet. Mindre $\delta$ = mer nøyaktig svar, men tregere.
For toppunkt: snu ulikheten til f(x + delta) > f(x).

Halveringsmetoden — finn nullpunkt

Del 2

Bruker nullpunktsetningen: hvis $f(a)$ og $f(b)$ har motsatt fortegn, ligger nullpunktet mellom dem. Vi halverer intervallet om og om igjen.

def f(x):
    return x**3 - 2*x - 5

a = 1      # f(1) = -6  (negativ)
b = 3      # f(3) = 16  (positiv)

while b - a > 0.001:
    m = (a + b) / 2
    if f(m) * f(a) < 0:
        b = m            # nullpunkt i venstre halvdel
    else:
        a = m            # nullpunkt i høyre halvdel

print(f"Nullpunkt: x ≈ {(a+b)/2:.3f}")
# → Nullpunkt: x ≈ 2.095
Krav: Du må vite at $f(a)$ og $f(b)$ har motsatt fortegn før du starter. Sjekk dette først.

Geometrisk rekke

Sum av 10 ledd, $a = 2$, $k = 3$.

a = 2
k = 3
s = 0
ledd = a
for i in range(10):
    s = s + ledd
    ledd = ledd * k
print(s)    # → 59048

Figurmønster

Figur $n$ har $2n + 1$ prikker. Skriv ut figur 1 til 10.

for n in range(1, 11):
    prikker = 2*n + 1
    print("Figur", n, ":", prikker)

Lister og f-string

Pen utskrift med variabler i.

tider = [0, 1, 2, 3, 4]
for t in tider:
    h = -5*t**2 + 20*t
    print(f"Etter {t} s: {h} m")
f"{x:.2f}" = avrund til 2 desimaler.

Vanligste feil

  • Glemt kolon (:) etter for, if, def, while
  • Feil innrykk (Python er strengt!)
  • = (tildeling) vs. == (sammenligning)
  • Glemt å endre variabel i while → uendelig løkke
  • Skriv 2*x, ikke 2x

Tilpasse et program

På eksamen får du ofte ferdig kode. Strategi:

  1. Les linje for linje, skriv hva hver linje gjør på norsk
  2. Finn hva som må endres (start, betingelse, regel)
  3. Bytt ut minst mulig
  4. Test med en liten verdi du kan regne i hodet
  5. Skriv en setning på norsk om hva programmet gjør

GeoGebra — kommando-oppslag Del 2

▾

Hele denne seksjonen gjelder Del 2. Skriv kommandoer i CAS-feltet (linjen merket fx eller ÷). Bruk := for å definere funksjon, = i likninger.

Definere funksjoner

f(x) := x^2 - 5x + 6
g(x) := 2*1.05^x
f(3)           # regne ut f(3)
→ 0
Bruk := ved definisjon, ellers blir det bare en likning.

Løse likninger

Løs(x^2 - 5x + 6 = 0, x)
→ x = 2, x = 3

NLøs(exp(x) = 5x, x = 0)
→ x ≈ 0,259
Løs = eksakt. NLøs = numerisk (når Løs ikke får til).

Likningssett

Løs({2x + 3y = 12, 4x - 3y = 6}, {x, y})
→ {x = 3, y = 2}
Husk krøllparenteser { } rundt både likninger og variabel-listen.

Faktorisere og forenkle

Faktoriser(x^2 - 5x + 6)
→ (x - 2)(x - 3)

Forenkle((x^2 - 9) / (x + 3))
→ x - 3

Nullpunkt og skjæring

Nullpunkt(f)
→ alle nullpunkter til f

Skjæring(f, g)
→ punkter der f(x) = g(x)

Topp- og bunnpunkt

Ekstremalpunkt(f)
→ topp- og bunnpunkter

Ekstremalpunkt(f, 0, 10)
→ kun i intervallet [0, 10]
Hvis Ekstremalpunkt feiler: Løs(f'(x) = 0, x).

Derivasjon

f'(x)           # den deriverte
f'(2)           # stigning i x = 2
Derivert(f)    # samme som f'(x)

Tangent

Tangent(2, f)
→ likningen til tangenten i x = 2
Skriv x-verdien først, så funksjonen.

Regresjon

L = {(1,5), (2,9), (3,13), (4,16), (5,20)}
f(x) := RegLin(L)
→ f(x) = 3.7x + 1.5
  • RegLin — lineær
  • RegPoly2 — andregrad
  • RegEksp — eksponentiell
  • RegPot — potens
Bruk aldri årstall direkte! Sett startår = 0.

Trigonometri

sin(60°)           → √3/2
arcsin(0.5)        → 30°
Vinkel(B, A, C)    # vinkel i punkt A
Avstand(A, B)      # lengde AB
Glemmer du °, regner GeoGebra i radianer (helt feil svar!).

Asymptoter

Asymptote(f)
→ alle asymptotene til f
Eks: $f(x) = (3x+1)/(x-2)$ → asymptoter $x = 2$ og $y = 3$.

Vanlige CAS-feil

  • Glemt := ved definisjon
  • Glemt ° for vinkler
  • Glemt gangetegn: skriv 2*x eller 2x, ikke 2 x
  • Glemt variabel i Løs: Løs(x+y=4, {x,y})
  • Glemt krøllparenteser i likningssett
